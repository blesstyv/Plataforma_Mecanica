
# Plataforma Educativa de Mecánica Industrial

Plataforma web educativa para organizar, administrar y compartir recursos de aprendizaje de Mecánica Industrial.

## Tecnologías

- Frontend: React, Vite y TypeScript
- Backend: Django y Django REST Framework
- Base de datos: PostgreSQL
- Almacenamiento: servicio de objetos compatible con S3
- Control de versiones: Git y GitHub

## Funcionalidades previstas

- Portal público de materiales educativos.
- Administración de asignaturas y categorías.
- Gestión de archivos PDF, PPTX y otros formatos.
- Autenticación y autorización para el profesor.
- Visualización y descarga de material educativo.

## Estructura

- frontend/: aplicación web React.
- backend/: API REST desarrollada con Django.
- docs/: documentación técnica del proyecto.
